## Güncel kaynak · elementary esintisi / Haber / özgün simgeler

Yeni kaynak, macOS/Ubuntu iskelelerini doğal boyuta geçirir; Windows 11'de Başlat + başlatıcılar + görevleri tek merkez grubuna, durum simgelerini ayrı üst şeride alır. 15 ayrı özgün uygulama simgesi / 120 boyut çıktısı, yuvarlatılmış yan menüler, tek ve bütçe kontrollü XRender geçiş motoru ve **native C/GTK Haber** ortak PC / Pi / ARM tariflerine bağlıdır. [Kapsam, kullanım ve doğrulama sınırları](ELEMENTARY-HABER.md). Yeni merkez kapısı yalnız panel sınırını değil görünür simge şeridini ve üç pencereyle büyümeyi üç çözünürlükte sınar; sonucu henüz yoktur.

Yerel **445 test / 7 bağımlılık atlaması, 25,524sn**, ResourceWarning ölümcül; tam görsel renderer (120 özgün simge, 315.915 bayt), seçili ses hash'leri, hedefli Python / kabuk lint ve workflow eşliği geçti. **Yerelde C / GTK / ARM hedef kapıları yoktur.** İlk `a7e7099` CI'ında C Haber iki boyutta üç host tabanında geçti; Pi host başarılı, PC efekt kapısı cam aşamasında başarısızdır. [Hata ve sahiplik / Xfwm test düzeltmesi](ELEMENTARY-HABER.md). Yeni takip sonucu / merkez ve imaj kapıları ayrıca beklenir. 11 seçili doğal kayıt / 25 eşleme vardır; önceki on WAV değişmez. Bu yeni değişiklikler aşağıdaki tamamlanmış `79c6942` imajlarına mal edilmez.
