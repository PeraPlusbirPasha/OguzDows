## 512 MiB–1 GiB, yeni düzenler ve mağaza · son geliştirme

- **armhf hata onarımı:** imzalı ARMv6 Raspbian tabanı, bookworm, anahtarlar ve paketler korunur. Kilitli pi-gen şablonu önce hash ile denetlenir; debootstrap **sonrası**, ilk APT yapılandırmasından önce sınırlı retries / timeout ve armhf için APT `mirror+file:` taşıması yerleştirilir. Aynı Raspbian arşivinin doğrudan adresi birinci, resmî yönlendiricisi ikinci önceliktedir. ARM64 kaynak URI’leri değişmez. `pi-apt-adaptation.json` before/after + ayar hash’lerini kaydeder; bootstrap ağ hatalarını çözdüğü iddia edilmez.
- **Yerel APT kanıtı:** gerçek APT ile ağsız, geçici DOSYA deposunda ilk kaynak yokken ikinci kaynaktan paket indirme ve sonrasında bozuk paketin SHA-256 nedeniyle reddi geçti. Bu sentetik test deposundaki `trusted=yes` yalnızca test fixture’ıdır, **üretim kaynaklarına eklenmez ve imza doğrulaması kanıtı değildir**. Üretimde AllowUnauthenticated / insecure seçenekleri açıkça false kalır. Gerçek Raspbian ağ / armhf tam imaj sonucu ayrıca gereklidir.
- **Ortak bütçe:** PC amd64/i386, Pi armhf/arm64 ve dört ARM64 katmanı aynı `resource_policy` / tek-seferlik `resource_tune` işçisini taşır. 512 MiB → mini, LZ4 sanal kapasite 384 MiB; 1 GiB → light, 512 MiB. full tercihi güvenlik eşiğini aşamaz; 2 GiB ve altı / ARMv6 / nomodeset ile kompozitör kapalıdır. Özel zram ve disk swap ayarları ezilmez. Uygulama/sürücü/kayıt çıkarılmaz; frekans / voltaj / termal korumaya dokunulmaz.
- **Görünüm:** Mac üst panel + ortalı alt iskele; GNOME üst panel + sol Ubuntu-esintili iskele. Ayrı dört GTK/Xfwm teması ve bağımsız açık/koyu seçimi; OğuzDows’ta opak statik cam/Aero esintisi. İsteğe bağlı 0,94 alfa yalnızca alt çubuk / iskele arka planındadır; blur yoktur. Başlık ve kapatma düğmeleri opaktır. Tipli xfconf dizileri, eski skaler yedeğin göçü, geri alma, kişisel paneller/eklentiler ve ayrı onaylı panel yenileme sınanır. Gerçek panel yerleşimi/GTK için CI gerekir.
- **Düşük kaynak UI:** karşılayıcı ilk anda 2/7 sayfa kurar; kalan beş sayfa ilk ziyarette, galeri mini bütçede 160px önizlemelerle yüklenir. Aynı özellikler korunur; bellek kazancı ölçülmeden sayı verilmez.
- **Mağaza:** daha büyük tema simgeleri + kurulu olmayan uygulamalar için 28 özgün çevrimdışı rozet (48/64px), ayrı Aç eylemi ve kurulum sonrası durum yenilemesi. Parolasızlık yalnızca desteklenen kullanıcı Flatpak kurulumudur; sistem APT hâlâ yönetici doğrulaması ister. Root / kabuk / belirsiz desktop-ID başlatma reddedilir. Gerçek uygulama kurulum/başlatma henüz doğrulanmadı; API taklitleri paket işlemi değildir.
- **Yeni düşük RAM VM kapısı:** PC ISO hedef testine ayrı 512 / 1024 MiB tam Xfce boot + 120 sn yerleşme / altı örnek / OOM kontrolü eklendi. 2 GiB ölçümü ile raporları karıştırılmaz. Kodun eklenmesi testin gerçekten geçtiği anlamına gelmez; sonuçları ayrıca kaydedilecektir.
- **Yerel kontrol:** 358 test / 6 yerel bağımlılık atlaması; `ResourceWarning` ölümcül. Sekiz pencere dekorasyonu / tüm rozetler ayrı önbellek kökünde üretildi; iki resmî pi-gen ağacında 12 dosya/mimari audit ve shellcheck / pyflakes / whitespace / PC workflow eşliği denetlenir. Bu sandbox’ta tam C/GTK / Xvfb araçları bulunmadığından bunlar CI’da tekrar sınanacaktır. Eski koşular iptal edilmez / yeniden başlatılmaz; v1.0.0 etiketi ve sekiz dosyası değişmez.
