İndir → doğrula → dene

  1. Doğru paketi seç. PC mimarisi, Pi modeli veya boş telefon emülatörü rehberini oku.
  2. Paket ile checksum’unu aynı klasöre indir. Tek paket için ona ait .sha256 dosyasını kullan.
  3. Özeti doğrula. Linux’ta aşağıdaki komutu çalıştır. Sonuç OK olmalı; uyuşmazsa dosyayı kullanma.
sha256sum -c OguzDows-amd64.iso.sha256
# Launcher için:
sha256sum -c OguzDows-Mobile-2.0-Akinci-debug.apk.sha256

PowerShell: Get-FileHash .\OguzDows-Mobile-2.0-Akinci-debug.apk -Algorithm SHA256. Sonucu gösterilen özetle birebir karşılaştır. Checksum, imzalı ISO veya kötü amaçlı yazılım taraması iddiası değildir.
